# Fantastic — Fanta scanner (PoC)

Local proof of concept for the Digital Summit Asia lanyard game.

```bash
npm install
npm run dev
```

Open the URL Vite prints. Sign up, tap **Scan a lanyard**, line up a pass, and hit **Capture**. Camera needs HTTPS or localhost. On desktop you can **Use a photo** of a badge, or **Pick type instead**.

First of each type is +15, repeats are +5, with a 1-minute cooldown. Leaderboard is this-browser only until the live backend is wired.
